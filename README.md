# Netflix - Tela de Perfis

Projeto da disciplina de Frontend (P1): página web com HTML e CSS puro recriando a tela de seleção de perfis da Netflix.

## Funcionalidades

- Tela inicial "Quem está assistindo?" com 4 perfis.
- Cada perfil tem um link que leva para uma tela de navegação (simulação do catálogo).
- Tela de "Gerenciar perfis" com ícone de edição sobre os avatares e opção de adicionar perfil (apenas visual, sem funcionalidade real).

## Tecnologias

- HTML5
- CSS3 (sem JavaScript)

## Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador.
